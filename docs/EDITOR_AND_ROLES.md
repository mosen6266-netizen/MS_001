# 剧本编辑器与角色匹配 — P0 不可变合同
## 消息编辑表单
- 发言账号：基于当前登录账号自定义备注的可搜索下拉框；不通过手输入假定登录人。
- 消息类型：文字、图片、图文；拖拽上传、替换、删除、预览、文字换行/英文/emoji/链接。
- 时间设置：发送前等待 preSendDelayMs（默认 5000ms，0–3600000ms）→ 正在输入 typingDurationMs（默认 5000ms，0–60000ms）→ 发送实际消息 → 回执 → 发送后等待 postSendDelayMs（默认 0ms）。
- 输入时间选项：关闭、3、5、10、15、30 秒、自定义 1–60 秒；编辑页排列顺序就是发言账号→消息内容→发送前等待→正在输入时间→发送后等待。
- 示例：preSendDelayMs=30000、typingDurationMs=5000 => 第 0–30 秒纯等待（无输入状态）、第 30–35 秒执行 typing 状态、约第 35 秒提交 send；总计 35 秒加网络传输时间。二者绝不同时计时、不能把后 5 秒算进前 30 秒。
- 三项时间可设置剧本默认值、单条覆盖、批量修改，复制/导出/导入后必须原值保存。
- “正在输入”是否在接收端全程可见取决于 Telegram，客户端必须使用官方允许的 typing 或 upload action，不能保证固定持续展示。
## 角色与导入
- 剧本只保存 `roleKey` (UUID)、`roleLabel`（自定义备注）、消息步骤/媒体，不得保存账户 ID、手机号、会话或任何机密信息。
- 匹配规则：Unicode NFC + 去两端空白后的完整备注精确匹配；本机登录总数量不限，只要覆盖本剧本所有使用过的角色即可。不要用子串或模糊匹配错配。
- 同名备注有多个可用账号时：先看目标群成员和发送权限，仍存在多个候选则人工选择，缓存本机×群话题×角色绑定。
- 点击开始必须逐群预检角色是否齐全、实际授权登录状态、群内权限、慢速模式、目标话题、媒体完整性、任务冲突。缺哪个备注就准确显示哪个；预检不通过阻止运行，不静默跳过。
- 同一剧本多个群的映射互相隔离，执行开始后锁定账号绑定与已发布剧本 revision；编辑草稿不修改正在运行任务。
- 操作：添加、复制、删除、批量更改时间、拖拽排序、撤销重做、快捷键、自动保存/已发布版本、草稿恢复。
## 关键验收
1. 等待30s + 输入5s + 发送 = 不早于35s提交发送，虚拟时钟单元测试检查阶段严格不重叠。
2. 等待0s+输入0s立即提交；暂停/恢复不丢剩余秒数；结束不能留输入状态。
3. 导入者有额外账号仍成功；缺备注时全部列出；重复备注不可随机选人。
4. 剧本媒体的相对路径、哈希、版本/大小与 ZIP 路径穿越保护必须校验。
5. 账号权限变化必须阻止/暂停对应群任务，不得换其他账号绕过平台限制。
