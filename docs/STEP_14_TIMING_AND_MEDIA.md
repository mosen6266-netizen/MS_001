# 第14步｜三段时间及图片/图文编辑

2026-10-16，仓库 `mosen6266-netizen/MS_001`。本步开发草稿编辑、图片本地存储与合成纯计时测试；不连接真实Telegram，不声称已发出任何消息。

## 用户已固定的计时合同
1. 顺序严格为 **发送前等待 `preSendDelayMs` → 正在输入 `typingDurationMs` → 进入实际消息发送阶段 → 确认发送/回执后发送后等待 `postSendDelayMs`**，四个阶段不会把时长重叠计算。
2. 例如30秒发送前等待、5秒正在输入、12秒发送后等待：理论上30秒无输入，接着5秒打字状态预览，第35秒才进入发送阶段；发送成功回执以后再等待12秒。网络交互时间另计，Telegram是否展示`typing`需遵守平台反馈，不能承诺状态持续可见。
3. 剧本新建默认 **5/5/0 秒**；可在剧本默认值处调整，新消息继承默认；现有消息保留各自覆盖值。单条分别设置、选中多条按勾选时间维度批量修改，支持0/3/5/10/15/30秒及自定义。正在输入≤60秒，前后等待各≤3600秒。
4. 旧草稿存在毫秒级小数值时必须无损保留，不得在读取/编辑/复制/保存时擅自四舍五入；界面新选择以秒为主。脚本内每项都保存为独立毫秒字段，没有含糊的共享倒计时。
5. `src/Features/Scripts/Timing/TimingPreview.cs` 只给出没有系统时钟/网络发送的纯时间线，用虚拟输入模拟发送确认后才开始后等待。真正暂停/恢复、延时发送、官方`typing`和回执调度在后续任务模块实施。

## 图片和图文素材架构
- `src/Features/Scripts/Media/MediaAssetStore.cs`：支持**PNG/JPEG/WebP**，每张不超过5MiB，解析文件头尺寸，尺寸1—8192像素，核对 MIME 与实际格式。文件名展示前消毒，禁止路径遍历；实际保存路径由本机应用数据目录与 `SHA-256` ID 组成，前端无法决定文件路径。
- 写入采用临时文件+flush+同卷原子移动，相同图片只保存一份；本地目录总额128MiB；文件已存在时重新比对哈希；预览前再次核对哈希/大小/尺寸/类型。任何图片预览都不能任意读取文件系统路径，不上传云端。
- `MediaReference` 只存`assetId`（64位小写sha256）、`mimeType`、`byteLength`、`width`、`height`、`fileName`（安全展示名字），**不能保存文件系统绝对路径、图片二进制/Base64、登录会话、账户密钥**。草稿默认`media:null`，旧草稿无media继续有效。
- 账号及剧本安全：复制剧本和复制消息沿用同一内容哈希，不重复保存实体；“移除图片”只解除当前消息的引用，不立即永久删除共享文件，避免其他草稿仍引用同一素材。完整垃圾文件清理必须在后续备份/发布/导出依赖规则确认后开发，不能抢先删除。
- `apps/desktop/MainWindow.Media.cs` 与 `IpcRequestGuard.cs`：仅`media.import`与`media.preview`两个经过独立大小上限和payload字段校验的本机命令；图片导入最多5MiB，经可信宿主验证后返回hash引用，预览返回受限dataURL。草稿保存请求仍最大512KiB；其他IPC通常最大8192字符，不允许把增大的媒体请求上限用于其他命令。
- `apps/ui/src/script-editor/MediaAttachment.tsx`：图片选择器、拖入文件、缩略图预览、替换/移除，异常显示中文信息，实际图片数据不进入编辑器快照；一条文字可结合图片成为图文消息，或留空成为纯图片。
- 保存和恢复时`EditorDocumentRules`与前端`isEditorDoc`双重验证图片hash、大小、文件显示名及三段时间。跨电脑带素材的ZIP导入/导出格式仍留给**第15步**，本步不会宣称文件可以直接迁移到新设备。

## 可视编辑器更新
- `TimingField.tsx`：预设与自定义秒数输入；每条卡片顺序为发言账号→消息正文→发送前等待→正在输入→发送后等待→图片；可在脚本头设置新消息默认值、批量对选中条目按勾选的时间项分别应用。
- `ScriptEditorPanel.tsx` / `state.ts`：所有修改走可撤销/重做的纯编辑状态机，保存失败不丢编辑内容；默认时间变更进入撤销历史并只影响新增消息；复制/拖拽及重排保留时间和图片引用；消息卡明确显示“第N秒进入发送阶段”的数学预览。
- 修复老草稿合法GUID/原有毫秒值识别问题，兼容旧 schema v5 的文字消息/已保存剧本，新字段均为可选、读取缺失值使用安全默认。
- 深色主题、中文字段、单独滚动区域、左侧固定导航及小屏自适应。真实 Windows WebView2 控件事件/文件选择拖拽最终仍需用户集中测试。
