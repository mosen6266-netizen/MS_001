# 第15步测试矩阵（开发）
- A三角色导出/B四账号导入；本机账号多于剧本角色可正常匹配。
- NFC+trim 精确备注；缺失角色全部列出、重复备注不随机选择；群权限筛选后的歧义仍需要人工确认。
- 30s/5s/12s 三段时间及历史1500ms无损；图片重复引用只打包一份并跨设备复原。

- 用户通过Windows原生文件选择器决定读写路径，输入无路径字段、无Telegram发送命令；空白/取消不写库。
- CI测试仅模拟跨设备，不代表Win10/11真实文件选择器、合法群授权/TDLib实机验收。
