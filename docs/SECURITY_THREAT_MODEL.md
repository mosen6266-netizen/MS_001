# 本地客户端威胁模型 — 2026-10-16

**资产**：后续真实授权账号会话、本人API配置、身份验证结果；当前本地 app.db UI元数据；日志/诊断、用户脚本、程序安装与升级文件。

**主要威胁与开发对应保护**：
1. 意外外泄账号秘密到源代码/日志/导出：.gitignore排除会话/凭据；严格事件枚举日志不接收任意文本；脚本按角色/昵称导出且不得包含会话和手机号；未来秘密只在专门隔离的保护区出现。
2. 恶意网页命令/超出信任边界的IPC：WebView2固定离线 origin，加载和弹窗导航限制；宿主在反序列化前执行 `IpcRequestGuard` 的协议/结构/长度校验；只读诊断不返回明细。
3. 机密文件被其他Windows用户读取：Windows CurrentUser DPAPI；备份和升级不能丢失/裸露秘密。**尚未为后续TDLib真实持久化完成完整加密设计**。
4. 明文异常信息泄漏：固定错误类别、通用中文用户提示，不把 Exception.Message、堆栈、原始 HTTP/IPC 发送给界面。
5. 数据损坏或磁盘错误：第04步WAL/FULL、升级前备份、迁移事务回滚；本阶段日志大小上限和无敏感内容；当前元数据备份仍非加密，发布前需评估是否包括敏感内容。
6. 测试伪证明：CI使用合成数据；标注 Windows runner DPAPI 检查与 Win10/11用户实机验收不同；不推断300账号可实际登录或50群同时发消息。
7. 软件供应链/图标合法性：发布前 pin native TDLib SHA、构建工具依赖、安装包签名、更新来源验证和品牌审查；不能宣称当前步骤完成了整套安全审计。

**明确不支持**：反垃圾限制绕过、多账号轮换规避平台风控、伪造多人对话；工具仅用于用户自有或获得明确许可的真实账号与群组沟通。

**验收等级**：`done_dev` 是源码+CI过关；DPAPI跨用户拒绝、攻击者模拟、故障/杀软/断电、崩溃dump清理和真实Windows/WebView2漏洞链验证属于最终专项测试，不能自动标PASS。
