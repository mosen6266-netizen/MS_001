# MOSEN Group Scheduler：运行和支持操作

这是MS_001当前离线开发基线；生产TDLib连接、50群实测和正式安装包尚待后续阶段。

## 查看历史
打开Windows桌面主窗口上方“任务历史”，可筛选普通、需注意、异常错误，固定每页10条。刷新按钮从本地已保存模拟任务及投递事件提取安全状态，不会创建、发送或恢复任务。顶部“异常历史”是第22步的独立通知记录。

## 导出诊断包
在“任务历史”中点击“导出脱敏诊断ZIP”，使用Windows文件保存对话框。只会生成manifest.json、summary.json和timeline.jsonl，提供随机支持编号与至多200条固定类型事件。
不包括聊天/群ID、手机号、消息正文、运行ID、投递ID、账号/会话、授权资料、原始日志、数据库或路径。把包发给经过确认的支持联系人；不要发送整个应用数据目录。

## 保留和清理
在“保留与清理”中选择保留7、30、90、180或365天，或清空全部派生历史。必须输入精确确认词“清理历史”后才会执行。数据库清理仅影响V10历史表并产生审计标记，不影响V7模拟任务、V8回执、V9隔离记录、剧本与停止标记。
诊断文件保留策略目前提供独立库接口，仅处理events.jsonl和events.previous.jsonl；原生窗口没有直接清理这两个文件的入口。

## 故障与恢复
网络异常和不明回执应先人工复核，不应盲目重新发送。全局紧急停止会锁闭本地模拟出站许可并停止模拟任务；历史清理、导出或刷新不会解除此锁。
Windows10/11真实窗口、文件对话框、锁屏、断网、持续运行与TDLib真实行为仍需最终验收。
