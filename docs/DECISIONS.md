|---|---|---|
| ADR-001 | 方案 A：真实授权 Telegram 账号，底层首选 TDLib | 已确认 |
| ADR-002 | 唯一工作仓库 `mosen6266-netizen/MS_001`；不能碰 Signal MS002 | 已确认 |

| ADR-007 | 图片、文字+图片、媒体打包；导入剧本不携带 Telegram 会话 | 已确认 |

| ADR-009 | 默认关闭主窗口即退出，不可默默继续后台发消息 | 已确认 |
| ADR-010 | 图标：用户提供 400×400 WEBP 原图，需透明化转换与商标合规检查 | 已收到素材；正式发布门禁 |
| ADR-011 | Cloudflare 授权沿用设计但对旧 MS002 生产资源完全隔离 | 已确认 |

| ADR-013 | 只用于已授权账号/群组，遵守 Telegram 平台限制 | 固定要求 |
## 需要在后续适当阶段确定
- 正式产品名称与第三方商标合规用图标（不可冒称 Telegram 官方应用）。
- 卡密是否跨软件通用、是否需要新的独立许可商品及设备上限。
- 最低/推荐硬件配置、最多同时连接会话数量均由实际压测得出，不得擅定。
- 生产 Cloudflare 变更及真实 Telegram 登录/发送需要单独批准。
