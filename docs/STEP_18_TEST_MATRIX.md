# 第18步开发期测试矩阵

- 安全入口：只有 `Running/AwaitingSend` 可以申请；冻结账号、群与话题必须完全匹配，禁止自动换号、提前发送或空消息。
- 官方事实：过期30秒授权、未来时间、未授权、没有本次权限刷新、成员资格过期、无法发文字或照片、频道/关闭话题均拒绝。
- 单账号串行：同账号跨群、并发40请求及50群并发模拟，只产生一条许可；跨账号同群需等待群频率窗口。
- 发送保护：令牌必须精准匹配才能结束；未知送达必须人工核对，不允许当作失败直接释放或盲目补发。
- 慢速与频率：成员慢速模式45秒；官方 Chat 等待对所有账号生效，账号 FloodWait 在所有群生效，对受影响群也生效；较短等待不得覆盖较长等待；每账号每分钟 <=6许可。
- Fail closed：安全最小间隔不可降低、关闭程序不能重新申请、无网络发送接口/无真实发送副作用。
- CI Windows/Linux全项目回归：WPF x64构建发布、SQLite v7、调度器、预检、媒体ZIP及前端回归。
- 最终实机 DEFERRED：真实服务端返回的错误码映射、账号即时授权、主题权限实时变化、持久生产outbox、多群长稳及合法群服务端实际发送。
